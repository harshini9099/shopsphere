## Reproduce on your machine

Follow the README prerequisites and start the backend, then run from the project root:

```bash
npm ci
npm run build
npm run typecheck
npx playwright install chromium
npx playwright test --project=api --project=chromium
npm run report
```

For PostgreSQL validation, run the full Compose stack and set `PW_SKIP_WEBSERVER=1` as documented in the README before running the tests. GitHub Actions provides an additional PostgreSQL + Chromium path after pushing the source to your repository.

The ZIP excludes temporary runtimes, node_modules, database files, generated credentials, runtime logs, failure traces and build outputs. Dependencies are installed using the supplied package-lock.json and Maven configuration. Reports are generated by your own test run.
